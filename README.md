# INT6064 小组项目 · 鱼塘的可持续捕捞

Coding and Computational Thinking（INT6064）— Group Project

**在线 demo：https://int6064final.vercel.app/**

用 Python 探究「一个鱼塘一年最多能捕多少鱼」——Logistic 模型 + 承载力 + 可持续捕捞，面向香港 S4–S5 中学生。

## 代码

| 文件 | 说明 |
|---|---|
| `web/index.html` | 引导式网页 demo（纯前端，canvas 可视化） |
| `logistic_map.py` | 约 10 行 Python 核心模型 |
| `Logistic映射-教学Notebook.ipynb` | Colab 填空版教学 Notebook |

## 主线（一句话）

鱼会生 → 塘有限 → 稳定在承载力 `P* = 1 − 1/r` → 卖得比增长少，就能可持续捕捞。
